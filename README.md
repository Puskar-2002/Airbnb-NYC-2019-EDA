# Airbnb-NYC-2019-EDA
Exploratory Data Analysis on Airbnb NYC 2019 Dataset using Python

# 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Airbnb NYC 2019 dataset to uncover meaningful insights related to pricing trends, neighbourhood demand, room type preferences, host activity, and revenue potential.

The analysis helps in understanding how Airbnb operates in New York City and provides data-driven business recommendations.

# 🎯 Business Problem

Airbnb wants to analyze its New York City listings to:

Identify high-demand neighbourhoods

Understand pricing distribution

Study customer room preferences

Evaluate host performance

Estimate revenue potential

Improve pricing and growth strategy

# 📊 Key Insights

🏙 Manhattan and Brooklyn dominate in listings and revenue.

🏠 Entire home/apartment is the most preferred room type.

💰 Most listings are priced below $300.

📉 Weak correlation between price and number of reviews.

👤 Some hosts manage multiple properties (commercial activity).

📅 High availability in some listings indicates potential low booking rates.
